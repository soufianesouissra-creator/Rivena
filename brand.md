# RIVENA brand

| Token | Hex | Use |
| --- | --- | --- |
| Near-black | `#0B0B0B` | Backgrounds |
| Deep red | `#8B0D1D` | Accent, buttons, logo mark |
| Light red | `#EC5869` | Red text on black (the deep red is too dark to read there) |
| Beige | `#E7D6C3` | Text and details on black |

- Logo: concept **"V1 Minimal"** (source: `design/icon` in the RIVENA-ME repo).
- The ERP currently uses `#850018` as its default `primaryColor` (`Company` model). It is close to, but not
  the same as, the brand's `#8B0D1D`.
- Typefaces already embedded in the ERP: **Space Grotesk** (titles) and **Inter** (text).
- Market: Morocco first. Client-facing copy in **French**, prices in **MAD (DH)**; Arabic/Darija for social
  where it fits.
